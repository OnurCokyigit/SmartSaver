SmartSaver is a mobile banking and stock investment application developed as a term project for the CENG427 course at Ankara Yıldırım Beyazıt University. The app allows users to manage their personal balance, buy/sell stocks with real-time pricing data, view transaction history, and analyze their financial statistics through intuitive charts and summaries.

The application includes both a local Node.js server (for database operations and transfer logic) and a native Android frontend that uses SQLite, SharedPreferences, and external APIs.
